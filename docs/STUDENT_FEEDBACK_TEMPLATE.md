## For the person collecting the forms

- Record the date, the engine version (ask the operator; Phase 5 is `extractive-1.4`) and the number of forms. Nothing else.
- If a student writes personal details in a free-text box, cross them out before the form is stored.
- Report counts per answer. Quote free text only without anything that identifies a person.
- Keep paper forms for one school term at most, then destroy them.
